What Alfred is

Alfred is a personal AI assistant run by a single private individual for their own use. It is not a commercial product, it is not offered to the public, and there is no way to sign up. Alfred runs on the owner's own computer, built on the open-source Hermes Agent software. The owner talks to Alfred through a private Telegram chat.

What Alfred does with Google

Alfred has its own Google account. With the owner's consent, Alfred uses Google sign-in (OAuth) to access that account's own Gmail and Google Calendar so that it can:

  • read, search, draft and send emails on the owner's request,
  • read calendar events, create and update appointments, and send reminders.

Alfred acts only when the owner asks it to, or on schedules the owner has set up. Google user data is used only for these tasks. It is never sold, never used for advertising, and never shared with anyone else. Details are in the Privacy Policy.
