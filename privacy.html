Privacy Policy

Last updated: 15 October 2026

Alfred is a private AI assistant used by a single individual (the "owner") for personal purposes. It is not available to the public. This policy explains how Alfred handles data it receives from Google APIs.

Which Google data Alfred accesses

Alfred signs in only to its own Google account (alfredocpennyworth@gmail.com), with the owner's consent. Depending on the permissions granted, it can access:

  • Gmail: messages, metadata and drafts, to read, search, write and send email.
  • Google Calendar: events and calendars, to read, create and update appointments.

How the data is used

  • Only to carry out tasks the owner requests, or schedules the owner has set up (for example summarising new email or sending a reminder).
  • Never for advertising, never sold, and never used to build profiles for anyone else.
  • Never used to train general-purpose AI or machine-learning models.

Where the data is processed

  • Alfred runs on a computer owned by the owner. Access tokens and Alfred's working notes are stored there.
  • To understand a request and write a reply, the relevant text (for example an email being summarised) is sent to an AI language-model provider (currently Ollama Cloud, with OpenRouter as a backup). This is done only as needed for the requested task.
  • Replies are delivered to the owner through a private Telegram chat.
  • No Google user data is shared with anyone else.

Retention and deletion

Google data is not copied into a separate database. Alfred may keep short notes in its local memory when the owner asks it to remember something. Access can be revoked at any time at myaccount.google.com/permissions; the stored tokens are then useless and are deleted from the computer.

Google API Services User Data Policy

Alfred's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
